# Muzică proprie (opțional)

Jocul generează singur muzica fiecărei facțiuni. Dacă vrei altă muzică, pune aici:

- `music_usa.mp3` — se cântă când joci cu SUA
- `music_ussr.mp3` — se cântă când joci cu URSS

Fișierele se cântă în buclă (pornesc în streaming, nu trebuie descărcate complet); dacă lipsesc, se folosește muzica generată. După ce le schimbi, site-ul trebuie reconstruit și republicat pe `gh-pages`.
